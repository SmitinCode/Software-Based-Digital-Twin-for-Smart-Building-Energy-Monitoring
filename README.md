# 🏢 Smart Building Digital Twin

A software-based Digital Twin mini project for simulating and monitoring
energy consumption in a smart building.

## 📌 Project Overview

This project demonstrates the basic concept of a Digital Twin using a
virtual smart building.

The system simulates:

- Multiple rooms
- Occupancy
- AC status
- Light status
- Fan status
- Energy consumption
- High-energy alerts

## 🔄 Digital Twin Workflow

Physical Building (Simulated)
        ↓
Building Data
        ↓
Virtual Digital Twin
        ↓
Energy Calculation
        ↓
Visualization
        ↓
Energy Alert

## 🛠️ Technologies

- Python
- Google Colab
- Pandas
- Plotly
- IPyWidgets

## 🚀 Features

- Interactive room selection
- Occupancy simulation
- AC ON/OFF control
- Light ON/OFF control
- Fan ON/OFF control
- Real-time energy calculation
- Energy visualization
- High-energy alert
